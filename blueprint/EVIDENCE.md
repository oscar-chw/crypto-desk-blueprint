# Evidence: the experiments behind the design rules

Each design rule that matters has an experiment with a **control arm** and a stated **falsification
condition**, specified in its stage file under `## Evidence`. Each one is a script in
[`experiments/`](../experiments) that writes `results/EXP-*.json` with its inputs, seeds, both arms, an
effect with its standard error and a verdict decided by the rule written in the script's docstring.

Rules for running them: the seed and the generating process are fixed in the script; the control runs
in the same run; each effect is reported with its standard error; a result inside noise is reported as
"no effect", not as support; a result that does not support its rule stays in the table.

Everything between the markers below is generated by `python scripts/run_experiments.py` from the JSON
files; none of it is typed by hand. Public data is a small committed extract checked against
[`data/MANIFEST.json`](../data/MANIFEST.json) (re-fetch with `scripts/fetch_data.py`), so every
experiment runs offline.

How to read a "does not support": the experiment ran as specified and the evidence went the other way
or stayed inside noise. The rule may still be right for a reason the experiment does not test; the
stage file says what the rule is for, and the JSON says exactly what was measured.
